# home_pkmt_variant

Попытка сделать новую, современную версию сайта ПКМиТ.


Next.js App Router, React, TypeScript и адаптивный CSS. Статический экспорт для Sites и любого статического хостинга.

## Запуск

Требуется Node.js 20.9+ и доступ к registry.npmjs.org.

```sh
npm install
npm run dev
```

Откройте http://127.0.0.1:3000. Для сборки: `npm run build`. Результат: `out/`.

## Реализовано

- Главная страница в инженерной стилистике: транспорт, машиностроение, энергетика.
- Каталог направлений, фильтрация и окна с квалификациями.
- Поиск разделов и специальностей.
- Мобильная навигация, адаптивные сетки для телефонов и планшетов.
- Повышенная контрастность, клавиатурный фокус, закрытие окон клавишей Escape.
- Блоки поступления, учебной базы, новостей, контактов.
- Ссылки на официальные документы и расписание, телефон и email.

## Контент

Источник: https://pkmt.edu.kz/index.php?kod_lng=2 . Специальности: /pdf/spisok_spec.pdf; правила приёма: /pdf/priem_rus.pdf; контакты: ?kod_lng=2&pgn=9; история: ?kod_lng=2&pgn=10; мастерские: ?kod_lng=2&pgn=41. Новости представлены краткими пересказами событий октября 2026 года. Изображения загружаются с сайта колледжа; шрифт Manrope — с Google Fonts, с системным fallback.

Это новый фронтенд. CMS, обработка заявлений и автоматическое обновление новостей не подключены. Казахская версия ведёт на официальный сайт. Официальные длинные названия некоторых специальностей сокращены для карточек; полный список доступен в исходном PDF.
